划词翻译 使用说明
====================

1. 解压整个文件夹（不要只拷出 exe），放在任意位置，双击「划词翻译.exe」。
   - 需要 Windows 10/11 64 位；无需安装 Python 或其他环境。
   - 首次运行若 Windows 提示"已保护你的电脑"，点「更多信息」→「仍要运行」
     （程序没有数字签名，属正常现象）。

2. 程序启动后常驻右下角系统托盘（蓝色"译"图标，可能在 ^ 折叠区里）。

3. 填入你自己的 DeepSeek API Key：
   单击托盘图标（或右键 →「设置…」）→ 填写 API Key → 保存，立即生效。
   key 在 https://platform.deepseek.com 申请，需少量充值；
   普通翻译约 0.001～0.005 元/次，学习模式约 0.004 元/次。请使用自己的 key。

   也支持其他 OpenAI 兼容的服务和本地模型（LM Studio / Ollama 等）：
   在设置里选「模型服务」或直接填「服务地址」，本地模型的 API Key 可留空；
   点「获取列表」可从服务端读取可用模型名。

4. 使用：选中任意文字，0.5 秒内连按两次 Ctrl+C，鼠标旁弹出译文浮窗。
   - 浮窗：可拖动；Esc 或点别处关闭；「固定」可常驻；「复制」拷走译文；
     「讲解」对当前这段文字用学习模式讲解一次。

5. 学习模式（设置里勾选，或点浮窗上的「讲解」）会给出：
   译文 / 断句（把长句按意群切开并说明每段作用）/ 变形解析（动词形容词怎么变形的）/
   重点词汇（带注音）/ 语法点 / 地道例句 / 小提示。

   浮窗上还有「总结」按钮：给出一句话总结和要点（用你的目标语言写）。

6. 设置窗口里可以改：
   - 翻译成（目标语言，默认简体中文）
   - 原文已是目标语言时，翻译成（默认 English；学日语可改成「日本語」）
   - 学习模式、学习者水平（低于该水平的词汇语法不讲）
   - 触发方式（默认双击 Ctrl+C，也可改成 ctrl+alt+t 这类组合键）
   - 开机自动启动
   - 「查询余额与用量」：账户余额 + 本地估算的今日/本月用量

7. 配置文件：%APPDATA%\划词翻译\config.json（一般不需要手动改）。
   退出：托盘图标右键 →「退出」。
